# 品質検証スキル

コミット前・PR前に必ず実行する品質チェックパイプライン。

## 実行手順

### Step 1: テスト実行
```bash
npm test 2>&1
```
- 全テスト合格を確認
- 失敗があれば原因を特定し修正

### Step 2: ビルドチェック
```bash
npm run build 2>&1
```
- TypeScriptエラーがないことを確認
- ビルドエラーがあれば修正

### Step 3: Lint（任意）
```bash
npm run lint 2>&1
```
- 重大なエラーのみ修正（warningは無視）

### Step 4: 結果報告

以下のフォーマットで結果を報告:
```
## 検証結果
- テスト: ✅ X スイート / Y テスト 全パス
- ビルド: ✅ 正常完了
- Lint: ✅ エラーなし
```

失敗がある場合:
```
## 検証結果
- テスト: ❌ X 件失敗（詳細: ...）
- ビルド: ❌ エラー（詳細: ...）
```

## 自動修正ポリシー
- TypeScript型エラー → 修正して再ビルド
- 構文エラー（orphaned code等）→ 修正して再ビルド
- テスト失敗 → 原因特定し修正
- 3回修正しても直らない → ユーザーに報告
