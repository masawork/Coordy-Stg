# プロジェクトクリーンアップ

## 対象

macOSのファイルコピーで生成された「2」付きの重複ファイルを特定・削除する。

## 手順

1. 「2」付きファイルを全てリストアップする
2. 各ファイルについて、オリジナルファイルとの差分を確認する
3. 差分がない場合: 削除対象としてリストに追加
4. 差分がある場合: ユーザーに報告し判断を仰ぐ
5. ユーザー確認後、一括削除を実行
6. 不要なドキュメント（IMPLEMENTATION_ISSUES_*.md 等の作業メモ）も確認

## 注意事項

- 削除前に必ずユーザーの承認を取る
- .git 内のファイルは絶対に触らない
- .env ファイルは触らない
